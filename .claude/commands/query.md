# /query — wiki/ 기반 질문 답변 스킬

wiki/ 문서를 탐색하여 사용자의 질문에 답변한다.
위키에 축적된 지식을 기반으로 답변하며, 반드시 출처를 명시한다.

사용자 질문: $ARGUMENTS

---

## 절대 규칙

- `wiki/index.md`를 반드시 먼저 읽는다.
- 답변에는 반드시 출처 `[[wikilink]]`를 포함한다.
- `raw/`는 wiki에서 답을 찾을 수 없을 때 마지막 수단으로만 접근한다.
- 위키에 해당 정보가 없으면 "위키에 해당 정보 없음"이라고 명시한다.

---

## 단계별 실행

### 1단계: 질문 분석

사용자의 질문에서 핵심 키워드와 의도를 파악한다:
- 종목명 (예: NVIDIA, 삼성바이오, SK하이닉스)
- 섹터 (예: AI/반도체, 바이오, 에너지)
- 개념 (예: PER, 모멘텀, 밸류에이션)
- 시장 동향 (예: 금리, 환율, 원자재)
- 전략 (예: 섹터 로테이션, 분산 투자)

### 2단계: index.md 확인

`wiki/index.md`를 읽어 관련 페이지를 식별한다.
질문의 키워드와 매칭되는 페이지 목록을 추린다.

### 3단계: 관련 페이지 탐색

식별된 관련 wiki 페이지들을 읽는다:
- `wiki/sectors/` — 섹터 관련 질문
- `wiki/stocks/` — 종목 관련 질문
- `wiki/concepts/` — 개념 관련 질문
- `wiki/strategies/` — 전략 관련 질문
- `wiki/market/` — 시장 동향 관련 질문

필요한 경우 페이지 내 `[[wikilink]]`를 따라 연관 페이지도 추가로 읽는다.

### 4단계: 답변 생성

수집한 정보를 바탕으로 답변을 작성한다:

1. **직접 답변**: 질문에 대한 핵심 답변을 먼저 제시한다.
2. **근거**: 답변의 근거가 되는 위키 내용을 인용한다.
3. **출처**: 참조한 wiki 페이지를 `[[wikilink]]` 형식으로 나열한다.
4. **관련 항목**: 추가로 참고할 만한 관련 wiki 페이지를 제안한다.

답변 형식:
```
### 답변
(핵심 답변)

### 근거
(위키 내용 기반 설명)

### 출처
- [[페이지1]]
- [[페이지2]]

### 관련 항목
- [[추가참고페이지]] — 간단한 설명
```

### 5단계: 정보 부족 처리

위키에서 충분한 답변을 찾을 수 없는 경우:

1. "위키에 해당 정보 없음"을 명시한다.
2. `raw/` 폴더에서 관련 자료가 있는지 확인한다 (마지막 수단).
3. raw/에서 관련 자료를 찾았다면:
   - 해당 내용을 바탕으로 답변하되, raw/ 출처임을 명시한다.
   - `/ingest` 실행을 권장한다: "이 자료를 wiki에 인제스트하려면 `/ingest`를 실행하세요."
4. raw/에서도 찾지 못했다면:
   - 현재 위키에 없는 주제임을 알린다.
   - 관련 자료를 `raw/` 폴더에 추가한 후 `/ingest`할 것을 제안한다.
